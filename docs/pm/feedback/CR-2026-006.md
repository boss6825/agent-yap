# Roadmap mode + deterministic placement quiz

## Signal
Founder idea, `plan.md` "Future direction: modes as lenses," priority 1
(repo-root-relative: `plan.md`). A hand-authored prerequisite graph (small JSON:
chapter/module -> prerequisites) across all seven modules, rendered as a roadmap
with Phase 2 completion rings on each node. Onboarding is a skippable 10-15
question placement quiz reusing the Phase 1 MCQ infrastructure; a score-per-
module rubric maps to a recommended entry node. Results in localStorage.

## Notes
`plan.md` ranks this **first among future modes**. Deliberately constrained:
"Pure lookup table, no AI, no tokens... Recommendations only, never locks."
Depends on the MCQ infrastructure (CR-2026-001) and completion rings
(CR-2026-004). Modes are "an index plus a renderer" over the same `content.ts`
slide list — no mode gets its own content. Lower weight: a future mode, not
Phase 1. Stays `logged`.
