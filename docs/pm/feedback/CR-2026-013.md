# LeetCode-style daily challenge (one question a day, no accounts)

## Signal
Founder, verbatim from the 2026-07-18 growth session: "we could also implement
leet code like gamification, which would help people to keep their interest in
this website," with the explicit constraint to keep the site simple and not
overwhelming.

## Notes
**Tension to resolve at triage:** `plan.md` non-goals currently say no
points/leaderboards, and CR-2026-004's notes argue streaks are for daily-habit
products. This CR is the founder explicitly asking for a LeetCode-like
mechanic anyway. The proposed resolution (see
`docs/growth/03-gamification-design.md`) is a moderated middle: a daily
question drawn deterministically from the quiz pool, an optional
localStorage-only streak counter with a built-in grace rule, no leagues, no
XP, no leaderboards, no notifications. If triage accepts it, `plan.md`
non-goals need a one-line amendment (human edit). Depends on CR-2026-001
(quiz blocks) landing first.
