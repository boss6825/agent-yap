# One interactive widget per book (differentiator)

## Signal
Founder idea, `plan.md` Phase 3, item 6 (repo-root-relative: `plan.md`).
Build 2-3 small interactive diagrams for concepts that most benefit from
manipulation — a context window filling up as you add tools/history, a RAG
retrieval pipeline you can step through, an agent loop simulator — embedded as
custom fenced blocks the same way as quizzes.

## Notes
`plan.md` frames Phase 3 as the **differentiator** and explicitly warns against
scope creep: "Do not try to widget-ify everything; one memorable interaction per
book is enough." Modeled on Subroute.dev ("small inputs, big intuition"). Reuses
the fenced-block rendering convention from CR-2026-001. Highest effort of the
Phase set; ships independently. Stays `logged`.
