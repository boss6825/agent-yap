# Updates feed: RSS/Atom + /changelog page

## Signal
Founder session directive, 2026-07-18 (reach push). Audit: no feed, no
changelog, no "what's new" surface anywhere; five module integrations
(CR-2026-011) are about to generate a stream of genuinely newsworthy entries.

## Notes
Feed entries are content events, not commits: book went live, chapter revised,
widget shipped, quarterly "state of agents" published. Implementation is a
route handler in the frontend lane reading a small hand-maintained changelog
source (no CMS). Email capture / newsletter is deliberately NOT part of this
CR; it gets its own CR if the feed shows demand. Cheap to build after
CR-2026-009's origin helper merges.
