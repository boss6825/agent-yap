# Make individual slides shareable: share button + Open Graph images

## Signal
Founder session directive, 2026-07-18 (reach push). Audit: no share/copy-link
affordance anywhere in the reader chrome; OG/Twitter cards declare
`summary_large_image` but ship no image at all.

## Notes
Two layers, shippable independently: (1) a quiet copy-link/share button in
`ReaderChrome` using the Web Share API with clipboard fallback; (2) a static
brand OG image first, then per-chapter `opengraph-image` generation. A later
extension (carousel export of a chapter's slides as images for X/LinkedIn) is
sketched in `docs/growth/05-distribution-and-seo.md` and should stay a
separate CR if demand shows up. Frontend lane; per-slide OG touches the SSG
slide route, which flips that slice to RIGOR.
