# 03 — Applications

Papers on how LLMs are deployed in real systems: tool use, frontier model overviews, long-context multimodal models, cost-efficient training, and software engineering agents.

---

## Papers

| # | Title | Year | Link | Notes |
|---|-------|------|------|-------|
| 1 | **Toolformer: Language Models Can Teach Themselves to Use Tools** | 2023 | [arxiv](https://arxiv.org/pdf/2302.04761) | Self-supervised method to teach models when and how to call external APIs |
| 2 | **GPT-4 Technical Report** | 2023 | [arxiv](https://arxiv.org/pdf/2303.08774) | High-level overview of GPT-4 capabilities (sparse on training details) |
| 3 | **The Llama 3 Herd of Models** ⭐ | 2024 | [arxiv](https://arxiv.org/pdf/2407.21783) | Deep dive into how Meta built Llama 3 — hyperparameters, data, configs, all public |
| 4 | **Gemini 1.5: Unlocking Multimodal Understanding Across Millions of Tokens** | 2024 | [arxiv](https://arxiv.org/pdf/2403.05530) | Multimodal model with 10M-token context window via mixture-of-experts |
| 5 | **DeepSeek-V3 Technical Report** | 2024 | [github](https://github.com/deepseek-ai/DeepSeek-V3/blob/main/DeepSeek_V3.pdf) | Frontier OSS model trained at a fraction of the cost of competitors |
| 6 | **SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering** | 2024 | [arxiv](https://arxiv.org/pdf/2405.15793) | Agent framework for autonomous GitHub issue resolution |
| 7 | **OpenHands: An Open Platform for AI Software Developers as Generalist Agents** | 2024 | [arxiv](https://arxiv.org/pdf/2407.16741) | Open-source software development agent platform (formerly OpenDevin) |

---

*Llama 3 (3) and DeepSeek-V3 (5) together give the best picture of how frontier models are actually built today.*
